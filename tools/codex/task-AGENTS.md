# Existing sd2snes task entry point

For work on `Ai-Slop-For-You/sd2snes`, the actual checkout is `work/sd2snes`
relative to this task directory. Read `work/sd2snes/AGENTS.md` before acting.
Use that absolute repository path for commands and delegated assignments;
do not treat this parent task directory as the firmware repository.

For substantial engineering requests, automatically read and follow
`work/sd2snes/.agents/skills/full-cycle/SKILL.md` (`$full-cycle`), which requests
bounded independent subagents and exact-commit review. For small edits, follow
the lightweight path in repository AGENTS.md. Delegated roles perform only their
assignment, without recursively starting a workflow. Do not apply this firmware
workflow to unrelated chat requests or other repositories.

Preserve all current work and completed milestones. Inspect status/history and
the Phase 1, handoff and Phase 2 docs; plan only remaining requested work.
Do not push, merge, flash hardware or expand scope without explicit authorization.
Model/config defaults do not switch an already-running task; use the role
settings and runtime limitations in `work/sd2snes/docs/CODEX_WORKFLOW.md`.
